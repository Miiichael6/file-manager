# Roadmap

## 1.6.2

- **Velikost ikon** (hlavní novinka): malé / střední / velké náhledy v zobrazení ikon – 64 / 96 / 128 px.
  Volba v menu Více → Zobrazit, v paletě příkazů (Ctrl+K) a přes Ctrl + kolečko myši; ukládá se
  do settings.json. Po vydání natočit znovu hero pro Store (`docs/store/hero/`) s velkými náhledy.

## Později

- Štítky jinak než barevnými tečkami ve stylu macOS (např. štítek-pilulka).
- Ikona Sdílet podle Windows 11 (dnes ikona ve stylu macOS).
- Ikona aplikace bez tmavého podkladu „squircle“ (šablona macOS Big Sur), ve stylu ikon Windows 11.
- Dialog kolize s formulacemi Windows (Nahradit / Přeskočit / Ponechat obě).
